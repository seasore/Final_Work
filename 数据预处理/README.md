# 数据预处理

根据开题报告要求，对电力负荷数据进行预处理，包括：

## 预处理步骤

1. **数据清洗**：去除重复时间戳、无效数据
2. **缺失值填补**：线性插值 + 前向/后向填充
3. **异常值处理**：
   - 负荷：IQR 方法（四分位距）
   - 气象：合理范围约束（温度 -20~50°C，湿度 0~100%，风速 0~50 m/s）
4. **标准化**：Z-score 标准化（仅用训练集拟合，验证集和测试集使用相同参数）
5. **时间特征**：小时、星期的周期性编码（sin/cos），是否周末
6. **相关性分析**：Pearson 相关 + 分组探索（季节、工作日/周末），量化负荷与特征的关联

## 数据来源

- `FuHe.xls`：负荷数据，15 分钟间隔，列：DATETIME, M019Value
- `(ky_weather).xls`：气象数据，日粒度，包含最高温、最低温、相对湿度、平均风速

## 输出（三分法）

- **训练集**：`数据/训练集/train_data.csv`（70%）
- **验证集**：`数据/验证集/val_data.csv`（15%，训练时调参/早停）
- **测试集**：`数据/测试集/test_data.csv`（15%，仅用于最终评估）
- **标准化器**：`scalers.pkl`（预测时需加载以反标准化）

## 分组与关联分析

开题报告要求：采用 Pearson 相关分析法量化气象因素对负荷的影响，分析不同季节、天气条件下负荷模式的差异。

- **是否需要分组**：训练/预测时按**时序滑动窗口**组织样本，不按物理分组存储。但在**分析阶段**需分组探索：
  - **按季节**：夏/冬季温度与负荷关联更强（空调、采暖）
  - **按工作日/周末**：用电模式不同
  - **按法定节假日**：含调休，使用 `chinese-calendar` 库识别
- **如何抓住关联**：
  1. **Pearson 相关性**：量化负荷与各特征的线性关系
  2. **分组相关性**：不同场景下关联强度可能不同
  3. **时序结构**：滑动窗口（如 96 步=24 小时）蕴含历史依赖
  4. **模型侧**：TCN-BiLSTM-Attention 的注意力机制会学习特征权重

运行 `python correlation_analysis.py` 可单独执行相关性分析，报告保存在 `correlation_report/`。

## 运行

```bash
cd 数据预处理
python data_preprocessing.py          # 完整预处理（含相关性分析）
python correlation_analysis.py      # 仅运行相关性分析
```

## 输出列说明

| 列名 | 说明 |
|------|------|
| DATETIME | 时间戳 |
| M019Value | 负荷值（已标准化） |
| max_temp | 最高温度（已标准化） |
| min_temp | 最低温度（已标准化） |
| humidity | 相对湿度（已标准化） |
| wind_speed | 平均风速（已标准化） |

| weekday_sin, weekday_cos | 星期周期性编码 |
| is_weekend | 是否周末 (0/1) |
